# Official download status

No official Rabbisir installation asset is available yet. The website's `Download · v0.1.0`
button opens this status record; it does not point to an App, DMG, ZIP, or update feed.

The confirmed first-release identity is `Rabbisir 0.1.0 · r1.00`. A real download may be added only
after the official App has been built from the accepted private candidate, Developer ID signed,
notarized, stapled, accepted by Gatekeeper, uploaded to the public GitHub Release, and verified from
the uploaded bytes. The download record must then name the exact asset, public Release URL, byte
size, SHA-256, supported macOS versions and architectures, and installation acceptance result.

`Rabbisir Open` is an unsigned, temporary local acceptance build made from public source. It is not
an official downloadable product and must not be uploaded or offered as the official App.
